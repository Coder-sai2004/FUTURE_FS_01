📌 Project Overview

This project is my personal professional portfolio website built as part of Task 1 of the Future Interns Full Stack Web Development Internship (2026).

The portfolio acts as my digital resume and project showcase, allowing recruiters, clients, and developers to learn about my skills, projects, and experience.

It is designed with a clean UI, responsive layout, and professional structure to represent my work and technical abilities.

🎯 Objective

The goal of this task was to build a modern, responsive portfolio website that includes:

Introduction and professional summary
Skills and technology stack
Projects I have built
Contact information for recruiters and clients

This portfolio demonstrates both my development skills and professional presentation as a developer.

⚙️ Installation & Setup

Clone the repository

git clone https://github.com/Coder-sai2004/FUTURE_FS_01.git

Go to project folder

cd FUTURE_FS_01

Install dependencies

npm install

Run the development server

npm run dev
📤 Deployment

The project is deployed using Netlify.

Steps used for deployment:

Push code to GitHub
Connect GitHub repository to Netlify
Select build command
npm run build
Publish directory
dist

Netlify automatically deploys the website.
